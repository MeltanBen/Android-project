# MyApplication（Task1）

学习如何创建安卓项目。

## 功能

显示 "Hello Android!" 页面

## 如何运行

1. 用 Android Studio 打开本文件夹
2. 等待 Gradle Sync 完成
3. 连接模拟器或真机，点 Run
